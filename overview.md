# Revenue Ripple - Project Overview

## 📋 **Project Summary**

Revenue Ripple is a comprehensive digital marketing education platform that combines online course delivery, affiliate marketing, and subscription-based business models. The platform teaches users various marketing skills while providing opportunities to earn income through affiliate commissions and reseller programs.

## 🏗️ **Technical Architecture**

### **Frontend**
- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS + Custom CSS
- **Key Libraries**: 
  - React Router for navigation
  - Framer Motion for animations
  - Stripe React components for payments
  - Chart.js for analytics
  - Radix UI for accessible components

### **Backend**
- **Framework**: Python Flask
- **Database**: Supabase (PostgreSQL)
- **Payment Processing**: Stripe (subscriptions + one-time payments)
- **Authentication**: Supabase Auth
- **Email Marketing**: GetResponse integration
- **AI Integration**: OpenAI API for assistant features

### **Infrastructure**
- **Hosting**: Render.com (configured via render.yaml)
- **CDN**: Public assets served via /public directory
- **Environment**: Production-ready with proper environment variable management

## 💼 **Business Model**

### **Revenue Streams**
1. **Membership Subscriptions** ($47/month) - Access to all courses and training
2. **Reseller Program** ($47/month) - Earn commissions promoting the platform
3. **Pro Reseller Program** ($97/month) - Higher commission rates and bonuses
4. **Tripwire Product** ($7) - Low-cost entry point (Digital Marketing Domination book)

### **Commission Structure**
- Standard affiliates earn commissions on referrals
- Resellers get enhanced commission rates
- Pro Resellers receive highest commission tier plus bonuses
- Multi-level tracking system for referral attribution
