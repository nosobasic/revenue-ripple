## GetResponse Setup Instructions

### Campaign Setup

1. **Create Tag:** `founders_annual`
2. **Create Automation:**
   - Trigger: Contact tagged with "founders_annual"
   - Actions: Send emails according to schedule above

### Automation Timeline:

```
Day 0, Hour 0, Minute 0  → Email 1: Welcome
Day 0, Hour 0, Minute 5  → Email 2: Discord Invite
Day 0, Hour 2, Minute 0  → Email 3: Vault Access
Day 1, Hour 0, Minute 0  → Email 4: Onboarding Reminder (conditional)
Day 7, Hour 10, Minute 0 → Email 5: Week 1 Check-In
Day 30, Hour 10, Minute 0 → Email 6: 30-Day Check-In
Day 50, Hour 10, Minute 0 → Email 7: Guarantee Reminder
```

### Custom Fields Needed:

- `FIRST_NAME` - Contact's first name
- `founders_annual` - Tag to trigger sequence
- `calendly_booked` - (Optional) Track if onboarding scheduled

### Integration with Backend:

The webhook in `server.py` automatically:
1. Tags new Founders Annual subscribers with "founders_annual"
2. Adds them to your GetResponse campaign
3. Triggers this email sequence

### Testing:

1. Test the sequence with your own email first
2. Verify all links work correctly
3. Check that timing is correct
4. Confirm conditional logic (Email 4) works
